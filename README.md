# Roblox Game: Zombie Shooter

A Roblox game where players can kill zombies, level up to shoot zombies, earn money, and get more money for new guns. This game includes a level system, zombie spawning, and gun management with upgrades.

## Install

1. Open Roblox Studio.
2. Create a new place.
3. Import the necessary models (zombie and gun models) into `ReplicatedStorage`.
4. Create a `ServerScriptService` folder in the Explorer.
5. Create scripts in `ServerScriptService` and paste the corresponding code from the provided files:
   - `MainScript` for the main game loop and player data initialization.
   - `LevelSystem` for handling player levels, experience, and leveling up.
   - `ZombieSystem` for managing zombie spawning, behavior, and interactions.
   - `GunSystem` for handling player shooting, gun upgrades, and money management.

## Use

1. Run the game in Roblox Studio.
2. Players will spawn with a starting pistol.
3. Kill zombies to earn experience and money.
4. Use the money to upgrade your guns.
5. Level up to unlock new guns and improve your shooting abilities.
